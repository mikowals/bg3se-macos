The post-build deploy step uses the shared resolver—external Steam libraries from `libraryfolders.vdf` plus the `BG3SE_GAME_PATH` override—and when BG3 is absent it warns and skips instead of failing the build. Set `BG3SE_GAME_PATH` to the application bundle or its containing directory for a nonstandard install. One note: `Documents/Larian Studios` is user data, not the game. Closing.
